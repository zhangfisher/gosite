# Default 站点设计规范

> **有机生物绿风格** (Organic Biophilic)
>
> 适用于企业官网、医疗科技产品、健康相关应用

---

## 设计理念

有机生物绿风格强调自然、健康和可持续性。通过有机形状、自然色调和柔和过渡，创造出舒适、可信赖的用户体验。特别适合医疗、健康、环保和科技企业。

### 核心价值
- 🌿 **自然有机** - 使用自然色彩和有机形状
- 🏥 **信任感** - 传达专业、可靠的品牌形象
- 🌱 **可持续性** - 体现环保和健康理念
- 💚 **健康关怀** - 温暖、亲和的用户体验

## 关键组件样式规范

### 1. 按钮（Buttons）

#### 主按钮（Primary Button）
- **背景色**：森林绿 500 (`#22C55E`)
- **文字色**：白色
- **圆角**：`lg` (12px)
- **内边距**：`12px 24px`
- **字重**：600 (Semibold)
- **悬停**：森林绿 600 (`#16A34A`)，轻微上移 1px
- **激活**：森林绿 700 (`#15803D`)，下移 1px
- **禁用**：灰度 30% 透明度
- **过渡动画**：200ms ease-out

#### 次按钮（Secondary Button）
- **背景色**：透明
- **边框**：2px 实线，森林绿 500
- **文字色**：森林绿 600 (`#16A34A`)
- **圆角**：`lg` (12px)
- **内边距**：`12px 24px`
- **悬停**：浅绿背景 (`#DCFCE7`)
- **过渡动画**：200ms ease-out

#### 文字按钮（Text Button）
- **背景色**：透明
- **文字色**：森林绿 600
- **悬停**：森林绿 700
- **下划线**：可选（悬停时显示）
- **过渡动画**：150ms ease-out

### 2. 卡片（Cards）

- **背景色**：白色或米白 (`#F5F5DC`)
- **圆角**：`xl` (16px) 或 `2xl` (20px)
- **内边距**：24px
- **阴影**：`shadow-md`
- **悬停效果**：阴影升级至 `shadow-lg`，轻微上移 2px
- **边框**：可选（1px solid `#BBF7D0`）
- **过渡动画**：250ms ease-out

### 3. 输入框（Inputs）

- **背景色**：白色
- **边框**：1px solid `#BBF7D0`
- **圆角**：`md` (8px)
- **内边距**：`12px 16px`
- **字号**：1rem (16px)
- **焦点状态**：
  - 边框色：森林绿 500 (`#22C55E`)
  - 外发光：`0 0 0 3px rgba(34, 197, 94, 0.1)`
- **占位符颜色**：`#9CA3AF`
- **过渡动画**：200ms ease-out

### 4. 导航（Navigation）

#### 顶部导航栏
- **背景色**：白色 + 柔和阴影
- **高度**：64px - 80px
- **Logo 区域**：左侧
- **导航链接**：
  - 常规：`#374151` (深灰)
  - 悬停：森林绿 600
  - 活动状态：森林绿 700 + 底部边框 (2px)
- **间距**：32px 链接之间
- **圆角**：导航按钮使用 `lg` (12px)

### 5. 标签（Tags/Badges）

- **背景色**：浅绿 (`#DCFCE7`)
- **文字色**：森林绿 700 (`#15803D`)
- **圆角**：`md` (8px) 或 `full`（药丸形）
- **内边距**：`4px 12px`
- **字号**：`0.875rem` (14px)
- **字重**：500 (Medium)

### 6. 模态框（Modal）

- **背景色**：白色
- **圆角**：`2xl` (20px)
- **最大宽度**：500px
- **内边距**：32px
- **遮罩层**：`rgba(5, 46, 22, 0.4)` (深绿半透明)
- **阴影**：`shadow-xl`
- **动画**：淡入 + 上移，300ms ease-out

### 7. 表单（Forms）

- **标签**：
  - 字号：`0.875rem` (14px)
  - 字重：600
  - 颜色：`#374151`
  - 间距：标签与输入框 8px
- **帮助文字**：
  - 字号：`0.75rem` (12px)
  - 颜色：`#6B7280`
- **错误状态**：
  - 边框色：`#EF4444`
  - 错误文字：红色 500
- **验证成功**：
  - 边框色：森林绿 500
  - 图标：绿色勾号

## 设计原则

### 1. 自然有机
- 使用有机形状和曲线，避免生硬的直角
- 运用 SVG 流动形状作为装饰元素
- 圆角使用 16-24px，营造柔和感

### 2. 健康友好
- 色彩系统基于自然绿色系
- 充足的留白，避免拥挤
- 字体大小符合可读性标准（最小 14px）

### 3. 可信赖感
- 保持视觉一致性
- 使用专业、清晰的排版
- 避免过度装饰

### 4. 可访问性
- **对比度**：所有文字与背景对比度至少 4.5:1
- **焦点状态**：所有交互元素有明显的焦点指示
- **键盘导航**：完全支持键盘操作
- **屏幕阅读器**：提供适当的 ARIA 标签

### 5. 响应式设计
- **断点**：
  - `sm`: 640px
  - `md`: 768px
  - `lg`: 1024px
  - `xl`: 1280px
  - `2xl`: 1536px
- 移动优先设计
- 避免水平滚动

## 动画与交互

### 过渡时长
- **快速**：150ms - 微交互（悬停、焦点）
- **标准**：200-250ms - 常规状态变化
- **缓慢**：300ms - 复杂动画（模态框、页面切换）

### 缓动函数
- `ease-out` - 退出动画
- `ease-in-out` - 进入动画
- `ease-spring` - 弹性效果（谨慎使用）

### 交互反馈
- **悬停**：颜色变化 + 轻微位移（1-2px）
- **点击**：按下效果（下移 1px）
- **加载**：提供加载指示器
- **成功/失败**：明确的状态反馈

### 尊重用户偏好
- 支持 `prefers-reduced-motion`，为不喜欢动画的用户禁用非必要动画

## 图片与图标

### 图标系统
- **推荐**：Heroicons、Lucide（SVG）
- **颜色**：继承文字颜色或使用森林绿色系
- **尺寸**：16px, 20px, 24px, 32px
- **圆角**：保持与整体风格一致

### 图片处理
- **圆角**：与卡片一致（16-20px）
- **阴影**：柔和阴影
- **懒加载**：使用 `loading="lazy"`
- **响应式**：使用 `srcset` 提供多尺寸

## 页面布局模式

### Hero 区域
- **高度**：至少 60vh（视口高度的 60%）
- **背景色**：浅绿渐变或纯色
- **内容对齐**：居中或左对齐
- **CTA 按钮**：使用主按钮样式
- **间距**：充足的内边距（64-96px）

### 特性网格
- **列数**：响应式（1/2/3 列）
- **卡片**：使用有机圆角
- **间距**：24-32px
- **悬停效果**：阴影 + 上移

### CTA 区域
- **背景色**：森林绿 500 或 600
- **文字色**：白色
- **圆角**：24-32px
- **内边距**：64-96px

---

## 反模式（避免使用）

❌ **不要使用**：
- 生硬的直角（0px 圆角）
- 过度鲜艳的霓虹色彩
- 暗色模式作为默认（需要时支持）
- Emoji 作为图标
- 过度的动画效果
- 低对比度文字（< 4.5:1）
- 瞬间状态变化（无过渡）
- 缺少焦点指示
